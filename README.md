# Student Grade Calculator

A beginner-friendly Python project that calculates student marks, percentage, grade, and pass/fail status.

## Features

- Accepts student name.
- Takes marks in five subjects.
- Calculates total marks and percentage.
- Assigns grades automatically.
- Displays PASS or FAIL.
- Validates marks between 0 and 100.
- Handles invalid inputs.

## Technologies Used

- Python 3
- Visual Studio Code

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python grade_calculator.py
```
